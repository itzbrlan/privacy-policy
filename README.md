## Troubleshooting

### GitHub Copilot API Version Error

If you encounter an error like "the specified API version is no longer supported" when using GitHub Copilot in VS Code:

1. Make sure you have the latest version of the GitHub Copilot extension installed
2. Reload VS Code window (Command Palette > "Developer: Reload Window")
3. The `.vscode/settings.json` file in this repository includes the correct configuration

To update the GitHub Copilot extension:
- Open VS Code Extensions panel (Ctrl+Shift+X / Cmd+Shift+X)
- Search for "GitHub Copilot"
- Click "Update" if available
- Restart VS Code
